# 浩汉

基于中国历史时间轴与同期世界国家轴的交互网站 Demo。

直接体验：用浏览器打开根目录的 `浩汉-demo.html`，无需安装依赖。下方命令用于继续开发源码。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；预览构建：`npm run preview`。

中国固定在国家轴首位，其余文明按当年与中国关系的密切程度排列，越靠前关系越密切；各国列使用与中国列相同的宽度。1937年1月的国家轴为中国、日本、朝鲜、美国、苏联、德国、英国、法国；朝鲜一列同时收录日本殖民统治下的半岛记录与海外独立运动，1938年后因暂无逐日档案不进入当年国家轴。国家列标题右上角显示当前年/月/日、分类及专题筛选条件下该国的可见事件条数，不再显示固定序号；较窄屏幕可横向滚动查看后面的国家。左侧是一把只显示时间的金属尺，支持从约前2070年到1949年的已收录年份；1937—1945年提供逐年抗战内容，其他年代为代表性节点。刻度断点表示未收录年份，间距不代表实际时间跨度。当前年份下以小字保留已选月份和日期。

“全部事件”旁的“更多”打开浮动标签面板，可搜索“西安事变”“高台战事”“《日出》讨论”等专题。每条事件只有独立的 `topicIds` 专题标签；政治、军事等分类只由顶部分类栏控制，不再作为事件标签显示。

未定日事件穿插在月内相邻日期附近：月初/上旬靠近1日，中旬靠近10日，下旬/月末放在当月最后一天附近；仅知月份的放在15日附近。日期刻度选择对应位置时也展示这些邻近活动，另保留“未定日”入口汇集所有月级记录。同一日期内的活动按政治、军事、战役、外交、经济、文化、社会的顺序排列，同类别保持资料录入顺序，不随渲染随机变化。排序与定位使用独立的展示位置，原始日期、月级精度和“未定日”标记保留，不把展示位置认定为确切发生日。

专题标签显示国别，如“中国 · 西安事变”“日本 · 日本内阁更替”；同名跨国专题按国家拆成独立标签。选择标签后仅过滤标注国家的事件列，与当前年/月/日和事件分类叠加；其他国家继续按原有规则显示同期事件。保留国家列、日期导航与当前国家，不切换到独立时间线。已选国别标签在分类栏显示，可单独清除；卡片和详情中的标签采用同样的筛选行为。面板支持搜索国别或专题，数量统计当前时间和分类条件下该国标签的记录；零条标签不会自动扩大时间范围。标签面板收起时不占额外页面高度，支持搜索、Escape和点击外侧关闭。

主画面直接展示各国的竖向历史事件轴，没有横幅、篇章大标题或表格。事件卡片悬浮在光轨旁，支持交错入场、悬停倾斜与卡片展开成详情浮窗。不同年代切换氛围色彩，背景有缓慢移动的雾光和尘粒。

点击年份或底部前后按钮切换时间，海外内容自动同步；点击事件标题展开详情，事件中的人物姓名可打开生平浮窗。国家、朝代、军队和机构名称作为文本显示；顶部国家按钮仍用于选择区域。人物浮窗展示独立撰写的生平正文，按早年、主要经历及后期生活等阶段展开，并显示生卒和生平资料来源。人物档案由72位增至364位，覆盖本次遍历的1937年1月八国375条事件中的姓名；标题、摘要和正文出现的人物统一汇入详情入口，正文支持姓名、简称及部分外文名点击，人物志支持别名搜索。内容不读取项目事件列表，也不受当前年/月/日、分类、专属标签或国家选择影响；不显示关联事件列表或事件跳转。资料不足者明确说明已知经历与缺口，不据同名材料补写人生。地名中的同形姓氏（如格鲁吉亚、吕贝克、考德贝克）以及人名命名的学校、公司、剧院和图书馆等不生成错误人物链接。拖动空白处、横向滚动或底部左右箭头探索其他文明，手机支持滑动。“聚焦”打开国家选择面板，默认按与中国关联度排序；可勾选要显示的国家并上下调整顺序，至少保留一个国家，“全部显示”恢复全部国家，“恢复默认”回到默认顺序。“时间漫游”每5.5秒推进一个已收录年份；1937年1月的“逐日漫游”逐天推进，到31日停止。打开浮窗时暂缓。支持关闭动效、系统减少动态效果设置、搜索、分类、键盘左右键以及浏览器本地典藏。
