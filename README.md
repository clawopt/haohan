# 浩汉

基于中国历史时间轴与同期世界国家轴的交互网站 Demo。

直接体验：用浏览器打开根目录的 `浩汉-demo.html`，无需安装依赖。下方命令用于继续开发源码。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。生产构建：`npm run build`；预览构建：`npm run preview`。

中国固定在国家轴首位，其余文明按当年与中国关系的密切程度排列，越靠前关系越密切；各国列使用与中国列相同的宽度。左侧是一把只显示时间的金属尺，支持从约前2070年到1949年的已收录年份；1937—1945年提供逐年抗战内容，其他年代为代表性节点。刻度断点表示未收录年份，间距不代表实际时间跨度。当前年份下以小字保留已选月份和日期。

默认打开1937年1月逐日档案，共77条活动：中国70条、日本3条、美国4条。中国有29个日期的定日记录；全样本含68条定日、2条跨日、1条约日、1条日期待核、5条月级记录。内容涵盖西安善后的文电和谈判、军内派别争论、红军调动与高台战事、所得税及工业生产、期刊与戏剧评论、人物的具体迁驻与编辑活动。没有为填满31天而虚构事件。

月、日下钻已移到左侧时间尺，年、月、日都以竖向时间轴呈现：点击另一个年份只切换年份，默认进入1月（该年没有1月记录时进入最早有中国记录的月份），不自动展开月日面板；再次点击当前年份才展开月份刻度，已有逐日档案的月份下可继续展开嵌套的日期刻度；选择没有逐日档案的月份时，应用该月并自动收起面板；全年、全月、具体日期和未定日等终点选择也会直接应用并收起面板。年月日采用同一金属尺、轴线与游标样式，没有月份网格或日历格。面板默认收起，悬浮在年份尺右侧，不占用事件区的顶部高度；点击外侧、关闭按钮、当前年份或按Escape收起，保留已选日期。点击同一月份只切换日轴的展开状态，不清除已选日期。1937年1月支持全月、任一日与“未定日”，可与分类及国别标签叠加。人物、派系、军队、机构的追踪栏已移除。跨日记录在其区间内继续展示，但不把已知战事区间改写为每天的详细战报。活动详情提供地点、正文、日期依据、直接来源及同日其他活动；海外事件按所引史料日期记录，不再逐条标注当地时间，未作全球时区统一换算。

“全部事件”旁的“更多”打开浮动标签面板，可搜索“西安事变”“高台战事”“《日出》讨论”等专题。每条事件只有独立的 `topicIds` 专题标签；政治、军事等分类只由顶部分类栏控制，不再作为事件标签显示。

未定日事件穿插在月内相邻日期附近：月初/上旬靠近1日，中旬靠近10日，下旬/月末放在当月最后一天附近；仅知月份的放在15日附近。日期刻度选择对应位置时也展示这些邻近活动，另保留“未定日”入口汇集所有月级记录。排序与定位使用独立的展示位置，原始日期、月级精度和“未定日”标记保留，不把展示位置认定为确切发生日。

专题标签显示国别，如“中国 · 西安事变”“日本 · 日本内阁更替”；同名跨国专题按国家拆成独立标签。选择标签后仅过滤标注国家的事件列，与当前年/月/日和事件分类叠加；其他国家继续按原有规则显示同期事件。保留国家列、日期导航与当前国家，不切换到独立时间线。已选国别标签在分类栏显示，可单独清除；卡片和详情中的标签采用同样的筛选行为。面板支持搜索国别或专题，数量统计当前时间和分类条件下该国标签的记录；零条标签不会自动扩大时间范围。标签面板收起时不占额外页面高度，支持搜索、Escape和点击外侧关闭。

主画面直接展示各国的竖向历史事件轴，没有横幅、篇章大标题或表格。事件卡片悬浮在光轨旁，支持交错入场、悬停倾斜与卡片展开成详情浮窗。不同年代切换氛围色彩，背景有缓慢移动的雾光和尘粒。

点击年份或底部前后按钮切换时间，海外内容自动同步；点击事件标题展开详情，事件中的人物姓名可打开生平浮窗。国家、朝代、军队和机构名称作为文本显示；顶部国家按钮仍用于选择区域。人物浮窗展示独立撰写的生平正文，按早年、主要经历及后期生活等阶段展开，并显示生卒和生平资料来源。全部72位人物均有独立介绍，内容不读取项目事件列表，也不受当前年/月/日、分类、专属标签或国家选择影响；不显示关联事件列表或事件跳转。资料不足者明确说明已知经历与缺口，不据同名材料补写人生。拖动空白处、横向滚动或底部左右箭头探索其他文明，手机支持滑动。“聚焦”打开国家选择面板，默认按与中国关联度排序；可勾选要显示的国家并上下调整顺序，至少保留一个国家，“全部显示”恢复全部国家，“恢复默认”回到默认顺序。“时间漫游”每5.5秒推进一个已收录年份；1937年1月的“逐日漫游”逐天推进，到31日停止。打开浮窗时暂缓。支持关闭动效、系统减少动态效果设置、搜索、分类、键盘左右键以及浏览器本地典藏。

主要代码：

- `src/data.ts`：事件、人物/文明、参考来源、年代与主题数据。
- `src/january1937.ts`：1937年1月活动记录、日期精度、来源和人物/组织档案。
- `src/topics.ts`：专题标签目录与现有事件的标签编排。
- `src/TopicPicker.tsx`：浮动标签搜索与选择。
- `src/personProfiles.ts`：补充人物生卒、生平节点、史料入口和日期分歧说明。
- `src/personBiographies.ts`：独立人物生平正文与补充传记来源，不依赖项目事件时间线。
- `src/App.tsx`：状态、浮动事件档案、搜索、典藏、人物生平浮窗。
- `src/ChronicleScene.tsx`：年份尺、左侧月日下钻、各国事件光轴、粒子氛围与漫游控制。
- `src/styles.css`：金属时间尺、悬浮档案、时代主题与响应式布局。

近代日期采用公历；远古保留约年和世纪精度。八年抗战在这里指1937—1945年全面抗战，十四年抗战自1931年开始。国家与政权的沿革分别解释，避免把1949年误写为中华民国灭亡。史料入口在事件详情及“史料与纪年说明”中提供；部分长卷节点属于同期概况，非单一事件。

日级样本主要依据陕西省图书馆专题文献、中央党史和文献研究院资料、地方志、教育机构档案及报刊文学研究。不同条目支持强度不一，部分只有一篇资料支持。写信、发令、刊出、到达、政策实施、实际到账分别处理，来源内部有差别的数字不强行取舍。人物生平依据党史、政府、图书馆、作家协会、总统图书馆及传记资料编写；生卒或具体日期不确定时保留“未详”、年/月精度和分歧说明。李志刚生卒及早晚年经历未详，王以哲、于学忠、马步芳、韩德勤等生年存在异文，宋子文去世日有异文，张学良去世日存在10月14日与15日异文。生平介绍并不意味着已穷尽人生的每一项活动。经济、文化、普通民众及其他地区的每日生活仍有覆盖缺口。

氛围插画通过指定图片生成服务加载，字体有系统宋体回退。页面可在图片或字体网络不可用时继续使用。Demo 无后端，典藏保存在当前浏览器的 localStorage。
